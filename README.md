# easyeda-analysis
Análise técnica do EasyEDA Standard e **Proto EDA** — editor esquemático web original.

- Documentação: `MASTER-REPORT.md`, `docs/`, `FEATURE-MATRIX.md`
- **Aplicação:** `prototype/` — `cd prototype && npm install && npm run serve` → http://localhost:8080/ (requer `npm run build` antes se servir estático sem script `serve`)
- Testes: `cd prototype && npm test` · E2E: `npm run test:e2e` (Node ≥ 20, Chromium via Playwright)
